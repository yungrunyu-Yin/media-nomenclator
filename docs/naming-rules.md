# 命名规则规格

本文是 MediaNomenclator 的命名格式规格。规则由 `skills/media-library-auto-rename/naming-config.example.json`
配置驱动，本文件说明配置项的实际含义与产物形态。

优先级：**用户当次明确指令 > 配置文件 > 本文件默认叙述**，
唯一例外是语言口径 —— 它不接受当次覆盖。

---

## 1. 命名模板

| 类型 | 模板 | 示例 |
|---|---|---|
| 剧集 / 动漫 / 综艺（单季） | `剧名.年份.SxxExx.「集标题」.扩展名` | `示例剧集.2021.S01E01.「示例集标题」.mkv` |
| 剧集 / 动漫（多季） | 同上，按 `第X季/` 分目录 | `第2季/某剧.2024.S02E01.「集标题」.mkv` |
| 电影 | `片名 (年份) 分辨率.扩展名` | `示例电影 (2010) 2160p.mkv` |
| 外挂字幕 | 与视频**完全同基名** | `示例剧集.2021.S01E01.「示例集标题」.ass` |

### 1.1 字段分隔

- **字段之间**用半角 `.`
- **标题内部**保留原有空格，不用 `.` `-` `_` 连接单词

```text
正确：Sample Show Name.2008.S01E01.Pilot.mkv
错误：Sample Show Name . 2008.S01E01.Pilot.mkv
错误：Sample.Show.Name.2008.S01E01.Pilot.mkv    ← 标题内部的空格被点号取代
```

### 1.2 无可靠集标题时

**省略整段**，不写空 `「」`：

```text
某部剧.2024.S01E02.mkv
```

## 2. 语言口径

**剧名与集标题一律「中文译名优先」，不分语种、不分存放目录。**

```text
多方查证中文译名
        ↓
能可靠确认 ──→ 用中文译名
        ↓
确认不了   ──→ 退回该作品的官方发行名称（英文 / 原文）
```

### 2.1 「能可靠确认」的标准

| 来源情形 | 是否采用 |
|---|---|
| 官方来源（官方发行名 / 官方平台 / 官方字幕）给出中文名 | ✅ 可直接采用（权威单源） |
| 主数据源给出中文名 **+ 1 个独立来源一致** | ✅ 可采用 |
| 只有主数据源一处 | ❌ 视为无法确认 → 退回官方原名 |
| 各来源互相冲突 | ❌ 退为无法确认 → 退回官方原名 |

> ⚠️ 同一数据源内的多语言变体（TMDB 的 `zh-CN` / `zh-TW` / `zh-HK`）**不算独立第二源**。

### 2.2 硬性禁止

- **禁止机器翻译**：译名必须来自可靠来源。
- **华语作品不转英文**：官方中文名即原名，直接采用，绝不为了统一格式改写。
- **不设当次覆盖例外**：不存在「这次改用英文名」的情况。

配置项：`defaults.titleRule`、`defaults.zhTitleSources`、`defaults.zhTitleAcceptance`、
`defaults.allowPerTaskLanguageOverride`。

---

## 3. 年份

使用作品**正式上映、首播或发行年份**。

- **单季作品**：条目首播年。
- **多季 / 续集**：**该季自己的首播年**，不是母剧首播年。

**不使用**：下载年份、文件创建年份、当前年份、文件夹修改年份。

配置项：`defaults.year`、`defaults.multiSeason.yearRule`。

---

## 4. 季与集

### 4.1 编号格式

```text
S01E01  S01E02  S02E01
多集合并：S01E01-E02
特典：S00E01
```

**不得写成** `1x01`、`01-01`、`EP01`、`Episode01`（除非原始资源本身需要保留特殊编号）。

### 4.2 多季与续集

| 要素 | 取法 |
|---|---|
| 剧名 | **该季的正式季名**；该季无独立季名才退回母剧名。季名只写后半段时补系列前缀成正式片名 |
| 年份 | 该季自己的首播年 |
| 季号 | 该季在系列中的序号，**不重置** |

**硬性检查**：所选条目下必须真的存在该季号，否则刮削会失败。

**冲突取舍**：电视台/发行方分季 ≠ 数据源分季 → **以数据源为准**（刮削是最终目的）。
此时文件名里的「季」标签与实际播出季不一致是刻意的。

**重复条目**：同一部剧可能有母剧条目 + 孤立单季条目 → 以母剧条目的季结构为准。

### 4.3 字幕集号换算

字幕发布组常按**实际播出季**编号，而视频可能已按数据源单季编号。
此时不能照抄字幕自带的 `S0xEyy`，必须整体顺延：

```text
实播 S2E01 → S01E(前序各季集数之和 + 1)
实播 S3E01 → S01E(前两季集数之和 + 1)
```

换算后**抽样读字幕正文**核对剧情与集号，确认无误再改名。

配置项：`defaults.multiSeason.*`、`defaults.multiSeason.subtitleEpisodeRemap`。

## 5. 集标题

### 5.1 来源优先级

1. 主数据源的 Episode Title（单源即可采用）
2. 官方平台 / 官方字幕
3. 豆瓣
4. Wikipedia
5. 其他可靠影视数据库

取**第一个真正给出集标题的来源**，并在 Dry Run 里注明来源。

### 5.2 两种假标题（必须排除）

| 类型 | 例子 | 处理 |
|---|---|---|
| 占位编号 | `Episode 1`、`第1集`、`EP05` | 视为**没有标题** |
| 聚合站自拟的分集描述 | 「第1集：某角色利用某关系拓展人脉」 | 不算集标题，不采信，也不算来源冲突 |

纯数字是**真实**集标题（例如 `737`、`51`），不得误判为占位编号。

### 5.3 引号

集标题一律用**全角直角引号** `「」` 包裹：

```text
示例剧集.2021.S01E01.「示例集标题」.mkv
Example Drama.2020.S01E01.「The Opening」.mkv
```

- 引号是标题的一部分，**不得省略**。
- 不得改用 `《》`、`“”` 或半角 `"`。
- 引号不计入「标题是否存在」的判断。

### 5.4 语言

```text
可靠中文集标题  →  用中文
可靠英文集标题  →  用英文（仅在无可靠中文时）
都没有          →  省略该段
```

**绝对禁止**：机器翻译、按剧情自编、为填满文件名强加不存在的标题。

配置项：`defaults.episodeTitle.*`。

## 6. 技术信息

| 类型 | 策略 |
|---|---|
| 剧集 / 动漫 | **不写任何技术信息** —— 文件名到「集标题」为止 |
| 电影 | **只写分辨率** |

```text
正确（剧集）：示例剧集.2021.S01E01.「示例集标题」.mkv
错误（剧集）：示例剧集.2021.S01E01.「示例集标题」.BDRip.1080p.H.264.FLAC.mkv

正确（电影）：示例电影 (2010) 2160p.mkv
错误（电影）：示例电影.2010.BluRay.2160p.HEVC.10bit.TrueHD.7.1.mkv
```

- 不使用 `[]` 包围技术信息（历史格式，已废弃）。
- 读不到可靠分辨率 → 留空 / `NEED_REVIEW`，**不补猜**。
- 文件夹名里的分辨率声明（如「4K」）属资源自带标注而非实测，是否采用**必须先问用户**。

### 6.1 字段表（历史参考）

字段顺序：`来源.分辨率.动态范围.编码.位深.音频.声道`

| 字段 | 取值 |
|---|---|
| 来源 | `WEB-DL` `WEBRip` `BluRay` `BDRip` `REMUX` `HDTV` `DVD` |
| 分辨率 | `2160p` `1080p` `720p` `480p` |
| 动态范围 | `SDR` `HDR` `HDR10` `HDR10+` `DV` `Dolby.Vision` `HLG` |
| 编码 | `H.264` `AVC` `H.265` `HEVC` `AV1` |
| 位深 | `8bit` `10bit` `12bit` |
| 音频 | `AAC` `AC3` `DD` `DD+` `DDP` `DTS` `DTS-HD.MA` `TrueHD` `Atmos` `FLAC` |
| 声道 | `2.0` `5.1` `7.1` |

音频与声道**同属一个音频组**，保持原有相对顺序（如 `DDP.5.1.Atmos`、`TrueHD.Atmos.7.1`），
不要把声道排到所有音频之后。

**两个已知坑**（`techinfo_reorder.py` 已内置保护）：

1. 声道号 `5.1` / `7.1` **内含点号**，与字段分隔符冲突 → 不先保护会被切成 `5` + `1` 而丢失。
2. 编码 `H.264` / `H.265` 内部也含点号 → 同样会被切成 `H` + `265`。

**不要堆砌**：文件大小、平均码率、GOP、色彩空间、色度采样、编码器版本、音频采样率、
封装器版本等一律不写。

配置项：`defaults.techInfo.*`。

## 7. 目录规则

```text
单季作品：
剧名/
├── 剧名.年份.S01E01.「集标题」.mkv
└── 剧名.年份.S01E01.「集标题」.ass

多季作品：
剧名/
├── 第1季/
├── 第2季/
└── ...
```

### 7.1 作品主文件夹

- 目标名 = **作品正式片名**（语言口径同 §2）。
- **不带年份**、不带分辨率/集数/发布组/英文名/来源标签。
- 多季合集用**系列母剧名**；单季作品用片名本身。
- 只重命名主文件夹本身，不移动、不增删内部文件。

```text
示例剧集[全12集]Sample.Show.2020.WEB-DL.2160p.H265.AAC-GROUP  →  示例剧集
示例剧集 1080P                                                →  示例剧集
Sample.Show.Name                                              →  示例剧集
```

### 7.2 季文件夹

统一为 `第X季`（阿拉伯数字）：

```text
Season01 / S01 / Season 1 / Season.01  →  第1季
第1季（2009）4K                        →  第1季
（季标题式命名，如「第三部长安」）      →  第3季
```

季号必须依据可靠数据源确认，**不能按目录出现顺序猜**。

### 7.3 绝不动的目录

- 分类层目录（如 `剧集/`、`电影/`）及其上层根目录
- 番外 / 特别篇 / 特别集 / 花絮 / 幕后
- `SP` / `Special` / `Specials` / `OVA` / `OAD`

### 7.4 单季作品的多余季目录

若单季作品被放进了 `第1季/`：先用数据源确认确为单季 → 把集文件**上移**到作品目录
（冲突策略 skip，绝不覆盖）→ 用 `delete_list.py` 清掉**已空**的目录（递归确认为零文件才允许）。
全程需用户确认。

配置项：`defaults.folderStructure.*`。

## 8. 字幕

### 8.1 同基名

```text
视频：示例剧集.2021.S01E01.「示例集标题」.mkv
字幕：示例剧集.2021.S01E01.「示例集标题」.ass
```

基名必须完全一致（含 `「」`），唯一允许不同的是扩展名。
支持 `.ass` `.srt` `.ssa` `.sub` `.vtt` `.smi`。

### 8.2 禁止语言后缀

不使用 `.zh` `.zh-CN` `.chs` `.cht` `.en` `.eng` `.ja` `.ko` ——
刮削器靠同名配对，不靠语言标记。

### 8.3 语言策略

```text
该集 ① 有简体字幕 且 ② 另有非简体版本  →  删掉非简体，只留简体
否则（没有简体替代）                  →  原样全部保留
```

- ★ **铁律：没有简体就一个都不许删**（否则用户没字幕可看）。
- **多个简体版本**：同一基名 + 扩展名前追加序号（`.2`、`.3` …）。这是唯一允许自动加序号的例外。
- **无语言标记** → 无法确证是简体 → **一律保留**。
- 删除走云端回收站，先列清单、默认 dry-run，且只经 `delete_list.py` 执行。

### 8.4 冲突

- 不同扩展名的同基名字幕可共存。
- 同一基名的**多个同扩展名**字幕 → `NEED_REVIEW`，不自动处理、不加语言后缀消解。
- 多语言同名字幕（`.sc` / `.tc` / `.jp`）去后缀后必然撞名 → `NEED_REVIEW`。

### 8.5 内封字幕

判断「有没有字幕」必须：**先看容器内字幕轨 → 再看外挂字幕 → 都没有才算缺**。
内封字幕**一律不动**（不改、不提取、不替换）。

配置项：`defaults.subtitle.*`。

## 9. 文件系统安全

Windows 禁止文件名包含 `\ / : * ? " < > |`。

遇到时的处理顺序：

1. 优先从可靠来源寻找合法写法
2. 若只是来源中的特殊标点，采用不影响识别的安全形式
3. 不得因非法字符导致整批失败
4. 无法安全判断 → `NEED_REVIEW`

**全角冒号「：」合法，一律保留** —— 只禁半角 `:`。

## 10. 检查清单

改名前逐项自查：

- [ ] 剧名是否走到「中文译名优先」流程，且有独立来源印证？
- [ ] 季集结构是否来自数据源条目，而非文件名推测？
- [ ] 所选条目下是否**真的存在**该季号？
- [ ] 集标题是否排除了占位编号与站点自拟描述？
- [ ] 无可靠集标题时，是否**省略**而不是硬填？
- [ ] 剧集文件名是否**不含任何技术信息**？电影是否**只含分辨率**？
- [ ] 作品目录是否**不带年份**？
- [ ] 字幕是否与视频**完全同基名**、无语言后缀？
- [ ] 是否已输出 Dry Run 并取得用户确认？
- [ ] 是否存在 `NEED_REVIEW` / `SKIPPED_CONFLICT` 未处理项？
